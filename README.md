# BioBot — Telegram-бот для запоминания терминов ЕГЭ по биологии методом мнемоники

Учебный продукт с интегрированным AI: помогает школьникам 10–11 классов запомнить термины генетики через визуальные образы и активное припоминание.

**Стек:** Python · python-telegram-bot · Anthropic API (Claude Haiku 4.5) · thefuzz
**Деплой:** Hetzner Cloud (systemd)

---

## Зачем этот бот существует

Термины генетики — *кроссинговер, конъюгация, плейотропия, эпистаз* — это слова греко-латинского происхождения, у которых нет интуитивной связи со смыслом для русскоязычного школьника. Механическое заучивание даёт слабый и быстро забываемый результат: в день экзамена ученик "видел этот термин", но не помнит, что он значит.

Бот решает эту задачу через **мнемонический метод ключевых слов** (Atkinson, 1975) в адаптации для русского языка, дополненный циклом активного припоминания и тремя режимами оценивания с разной когнитивной нагрузкой.

## Педагогический дизайн

### Учебный цикл из 5 шагов

1. **Семантизация** — ученик видит определение термина и понимает смысл
2. **Декомпозиция** — термин разбивается на фонетические части, каждая часть превращается в узнаваемое русское слово (*КРОС-cовок ГО-ловой ВЕР-тел*)
3. **Визуализация** — формируется яркий, абсурдный, эмоциональный образ
4. **Связывание** — образ совмещается со смыслом термина (*кроссовки обменялись головами → хромосомы обменялись участками*)
5. **Воспроизведение** — ученик называет термин, опираясь на образ

На каждом шаге бот спрашивает «Получилось?» и при отрицательном ответе возвращает ученика на предыдущий шаг. Это маленький цикл активного припоминания внутри одной карточки — то, что в когнитивной психологии называется *retrieval practice*.

### Три режима оценивания

Каждый режим даёт разную когнитивную нагрузку, что позволяет проверить запоминание на нескольких уровнях:

| Режим | Стимул → ответ | Когнитивная задача |
|---|---|---|
| **Б** | Определение → термин | Free recall — самый сложный |
| **В** | Термин → определение | Активное воспроизведение в развёрнутой форме |
| **Г** | Определение → выбор из 4 терминов | Recognition — самый лёгкий, для начинающих |

Логика «Г → Б → В» даёт педагогически обоснованную траекторию роста сложности.

### Учёт особенностей школьников

- **Опечатки прощаются** через fuzzy-matching (`thefuzz`, WRatio ≥ 80). Ребёнок не должен терять очки за то, что промахнулся клавишей.
- **Образы конкретны.** System-промпт запрещает абстрактные слова («свобода», «память», «душа») — только то, что можно увидеть, потрогать, нарисовать.
- **Абсурд как мнемотехника.** Необычные цвета, размеры и действия запоминаются мозгом в разы лучше реалистичных — это заложено в правила генерации.
- **Онбординг до старта.** Ученик сначала читает короткое объяснение метода, и только после подтверждения готовности начинает учить термины.

## AI в продукте

Claude (Haiku 4.5) встроен в две точки учебного процесса.

### 1. Семантический поиск термина

Ученик может ввести «обмен хромосом», «крусинговер» или «когда хромосомы обмениваются участками» — Claude находит правильный термин из базы, учитывая опечатки, синонимы и описания смысла.

### 2. Генерация альтернативных образов

Если статичный образ из базы не «зашёл» ученику, он жмёт «🔄 Другой образ» — Claude генерирует новый по строгим педагогическим правилам.

### System-промпт как педагогический документ

Главное в этой части проекта — не вызов API, а сам system-промпт. Он спроектирован как методические указания для генератора и содержит:

- **Правило 1** — количество слов в мнемонике зависит от длины термина (короткий → 1 слово, средний → 2, длинный → максимум 3)
- **Правило 2** — разрешённые и запрещённые категории слов (только конкретные существительные, никаких абстракций)
- **Правило 3** — порядок слов в мнемонике строго соответствует порядку фонетических частей термина
- **Правило 4** — обязательная «необычность» образа (неправильный цвет / размер / действие / ситуация)
- **Правило 5** — образ обязан отражать смысл определения (обмен → меняются местами; одинаковые → близнецы; и т. д.)
- **Эталонные примеры** для нескольких терминов в формате few-shot
- **Финальный чек-лист из 7 пунктов** перед выдачей ответа (модель проверяет себя)

Полный текст промпта — в [`services/claude_api.py`](services/claude_api.py).

## Архитектура

```
biobot/
├── bot.py                      # точка входа, роутинг сообщений и состояний
├── data/
│   └── terms.json              # база терминов с эталонными мнемониками
├── handlers/
│   ├── learn.py                # режим «Учить термин»: 5-шаговый учебный цикл
│   └── quiz.py                 # три режима проверки знаний
├── services/
│   ├── claude_api.py           # интеграция с Claude API + педагогический промпт
│   └── fuzzy_search.py         # прощение опечаток в ответах ученика
├── requirements.txt
└── .env.example
```

Состояние ученика хранится в `context.user_data` (in-memory). InlineKeyboard используется для callback-логики учебного цикла, ReplyKeyboard — для главного меню.

